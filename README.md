# TriageConnect.ca website

A static, mobile-friendly website designed for free hosting on GitHub Pages.

## Publish on GitHub Pages

1. Open your `triageconnect-website` repository.
2. Upload all files and folders from this package into the repository root.
3. Commit the files to the `main` branch.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.

## Before launch

- Replace the temporary `TC` mark with your final logo.
- Update `info@triageconnect.ca` in `contact.html` if needed.
- Replace or add photos in `assets/images`.
- Have healthcare legal/privacy professionals review all public claims and policies.
- Add Privacy Policy and Terms pages before collecting personal information.

## Custom domain

The included `CNAME` file contains `triageconnect.ca`. Do not configure GoDaddy DNS until the GitHub Pages test address is working.
